# miro

Miro's official hosted MCP server: search and read boards, summarize board content, and create boards, frames, sticky notes, shapes, docs, tables and diagrams; it can also share boards and spaces with users.

## Variables

None required: the server uses OAuth 2.1. Sign in on first use and pick the Miro team to install it on; only boards in that team are reachable.

## Notes

- The connection is team-specific; if a board is not found, re-authenticate and choose the team that owns it.
- On Enterprise plans an admin must enable MCP and can restrict how it is used.
- Tool calls count against daily limits that depend on your plan.
- Sharing tools change who can access boards; keep them behind approval prompts.

Docs: https://developers.miro.com/docs/connecting-to-miro-mcp
